# Agent instructions

## Agent skills

### Issue tracker

Track issues and specs as local Markdown in `.scratch/`. Before creating, fetching, or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles as issue status values. Before triaging issues, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the project, read `docs/agents/domain.md`.
